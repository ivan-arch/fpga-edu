# Lesson 10: AXI Timer, Zynq PS та MicroBlaze

Я маю на руках плату EBAZ4205 (колишня плата для майнінгу). На ній два
світлодіоди підключені до PL-частини, а одна кнопка — до PS-частини.
Тому я адаптував умови задачі під наявну периферію.

## Мій варіант задачі

- Перший діод блимає тричі, потім другий один раз, і так по колу.
- Кнопкою ми міняємо, який з діодів (червоний чи зелений) перший, а який другий.
- В обох варіантах (PS та MicroBlaze) зміна стану діодів і детектування
  натискання кнопки виконуються в перериванні AXI Timer: лічильник 0 крокує по станам діодів, лічильник 1 опитує кнопку.
- У варіанті з MicroBlaze я використав ще один GPIO-порт, бо без PS-частини
  немає доступу до фізичної кнопки.
- Варіант з MicroBlaze перевірено в симуляції. Для неї періоди таймера
  скорочено (`#define SIM 1` у коді).
